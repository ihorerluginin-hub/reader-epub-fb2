# Ридер — книги без посредников

Локальный читалка **EPUB** и **FB2**: своя библиотека, без аккаунтов, без подписок,
без сети и без слежки. Существует в двух ипостасях:

- **Веб-страница** — один файл `index.html`, открывается в любом современном браузере;
- **Android-приложение** — `android/` собирается в APK, внутри тот же `index.html`
  в WebView. В манифесте **нет ни одного разрешения** — ни `INTERNET`, ни хранилища.
  Приложение физически не может отправить ваши книги куда-либо.

## Манифест

Современные ридеры научили нас, что купленная книга — это аренда, а чтение —
услуга по логину и паролю. Этот ридер — маленькое возражение:

- **Без аккаунтов.** Ни логина, ни почты, ни «продолжить через Google».
- **Без подписок.** Чтение — не абонентская плата, а страница — не услуга.
- **Без сети.** Ни одного запроса в интернет. Откройте DevTools → Сеть и проверьте.
- **Без «облака».** Книги лежат в хранилище вашего браузера / в данных приложения —
  у вас дома, а не у кого-то ещё.
- **Один файл, ноль зависимостей.** Ни фреймворков, ни CDN, ни шрифтов из сети.
  Откройте `index.html` блокнотом — там нет ничего, чего вы бы там не хотели видеть.
- **DRM не читает — принципиально.** Книга с DRM не ваша, даже если вы за неё заплатили.

## Как пользоваться

### Веб

Просто открыть `index.html` в Chrome / Edge / Firefox / Safari (нужен браузер с
`DecompressionStream` — все современные). Для удобства можно поднять локальный сервер:

```
python -m http.server 8321
```

и открыть http://127.0.0.1:8321

Книги добавляются кнопкой «Добавить книги» или перетаскиванием файлов в окно.
Библиотека хранится в IndexedDB браузера: она останется после перезапуска, но
привязана к профилю браузера — чистка «данных сайтов» её удалит.

### Android

```
cd android
gradlew.bat assembleDebug
```

Готовый APK: `android/app/build/outputs/apk/debug/app-debug.apk`.
Установить на подключённый телефон: `adb install -r app\build\outputs\apk\debug\app-debug.apk`.

В приложении дополнительно:

- книги открываются из проводника через «Открыть с помощью» (EPUB/FB2);
- выбор файлов — через системный диалог (кнопка «Добавить книги»);
- пока открыта книга, экран не гаснет;
- системная кнопка «Назад» возвращает из книги в библиотеку.

Сборке нужен JDK 17+ (подойдёт JBR из Android Studio) и Android SDK (platform 37).
Интернет для сборки не требуется, если дистрибутив Gradle и плагин уже в кэше.

## Возможности

- **Форматы:** EPUB 2/3 (свой разбор ZIP + XHTML, без библиотек), FB2 (включая
  `.fb2.zip` и кодировку windows-1251), титульный лист собирается из метаданных.
- **Библиотека:** обложки из книги (или сгенерированные), поиск, сортировка,
  прогресс чтения, удаление.
- **Чтение:** постраничная вёрстка (CSS-колонки), листвание кликом по краям,
  колесом мыши, свайпом, клавишами ←/→/Space/PgUp/PgDn, ползунком; оглавление
  (EPUB3 nav / EPUB2 NCX / заголовки FB2); сноски и внутренние ссылки работают;
  прогресс запоминается и восстанавливается после переоткрытия и смены настроек.
- **Оформление:** 4 темы (светлая/сепия/тёмная/чёрная), кегль, интерлиньяж, поля,
  шрифт с засечками/без, выключка, переносы.
- **Гигиена:** из книг вырезаются `<script>`, `<style>`, обработчики `on*` и
  потенциально опасные стили; внешние ссылки открываются в новой вкладке.

## Устройство

```
index.html          — всё приложение: парсеры, библиотека, читалка (веб + assets APK)
android/            — обёртка: одна Activity с WebView + JS-мост, без зависимостей
make_fixtures.py    — генератор тестовых книг
fixtures/           — тестовые книги (epub, fb2, fb2.zip, windows-1251, drm)
test.html, cdp*.py  — прогон в headless-браузере (python cdp.py при запущенном
                      python -m http.server 8321)
```

Пагинация: книга целиком укладывается в CSS multicol-контейнер, страница =
колонка шириной в экран; позиции восстанавливаются по доле прокрутки, поэтому
смена кегля/полей не сбивает место чтения. ZIP вскрывается своим парсером через
нативный `DecompressionStream('deflate-raw')`.
